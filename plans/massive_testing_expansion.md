# 規模化測試擴充計畫 (Massive Testing Expansion)

## 1. 目標
將測試腳本規模提升 3-5 倍，從單點功能測試進化為 **RBAC 權限體系驗證** 與 **全鏈路業務流程測試**。

## 2. 核心擴充內容

### A. 特權帳戶與 RBAC 測試 (`tests/test_rbac.py`)
- **角色隔離驗證**:
    - 建立「商品管理員」帳號 (僅 `product=1`)，驗證其無法進入訂單管理或會員管理。
    - 建立「訂單管理員」帳號 (僅 `orders=1`)，驗證其無法新增商品。
    - 驗證「Root」帳號具備所有權限且無法被編輯/刪除。
- **非法存取阻斷**: 測試未登入人員或權限不足人員存取 API 路由時的重導向與 Flash 提示。

### B. 複雜業務場景 (`tests/test_complex_workflows.py`)
- **全鏈路 E2E 流程**:
    1. 管理員 A 新增商品與 SKU。
    2. 管理員 B 發布促銷優惠碼。
    3. 客戶 C 註冊、將商品加入願望清單、轉入購物車。
    4. 客戶 C 勾選部分商品並套用優惠碼結帳。
    5. 管理員 D 審核訂單並執行出貨。
    6. 客戶 C 收到貨後申請退貨。
    7. 管理員 D 審核退貨並更新庫存。
- **庫存競爭測試**: 模擬多個 Session 同時下單最後一件商品，驗證資料庫鎖定機制 (`FOR UPDATE`) 是否生效。

### C. 前端交互模擬 (`tests/test_frontend_interaction.py`)
- **多步驟表單流轉**: 模擬結帳流程中的 Session 資料遺失處理（如結帳中途跳回購物車修改數量後再結帳）。
- **非同步 API 模擬**: 測試購物車數量更新 (AJAX) 的響應格式與錯誤處理。

## 3. 環境加強 (`tests/conftest.py`)
- **`staff_factory`**: 動態建立具備自定義權限的員工帳號。
- **`persistent_client`**: 維持長連線 Session，方便模擬多步驟操作而不遺失狀態。
